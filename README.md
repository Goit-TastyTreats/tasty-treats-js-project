# TastyTreats

A recipe discovery web app built with JavaScript, HTML, and CSS.

Live Demo: https://goit-tastytreats.github.io/tasty-treats-js-project/

## Features
- Search and filter recipes by category, time, area, ingredients
- Save favorites (stored in localStorage)
- Order form with name, phone, email, comment
- Rate recipes
- Fully responsive (mobile, tablet, desktop)

## Technologies
- HTML5, CSS3, Vanilla JavaScript (ES6+)
- Vite (build tool)
- MealDB API
- GitHub Pages

## How to Run

1. Clone: git clone https://github.com/Goit-TastyTreats/tasty-treats-js-project.git
2. Install: npm install
3. Start: npm run dev
4. Open: http://localhost:5173
